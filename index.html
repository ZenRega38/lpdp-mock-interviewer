📋 Cara Pakai

  1. Masukkan Gemini API Key, pilih bahasa, pastikan Knowledge Base dimuat, lalu pilih mode sesi.

  3. Tahan tombol mic (atau Spasi) saat menjawab, lepas untuk mengirim. Di HP, ubah Mode Mikrofon ke "Klik" agar tidak perlu menahan.
  4. Idealnya tiap jawaban 30 sampai 90 detik; penghitung waktu berubah kuning/merah bila terlalu panjang.
  5. Klik Akhiri & Evaluasi untuk skor akhir.
